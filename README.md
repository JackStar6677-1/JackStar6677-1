Supports `DrakesRust`, `DrakesJava`, `Local Forge` (local server lifecycle supervisor, live stdout/stderr streaming, interactive stdin console, EULA/`server.properties` editor, Slimefun preset installer, and one-click world backups), and `Online` (**Minecraft Server List Ping `0x00`** + TCP latency), backed by 51/51 Rust unit & integration tests across Windows and Linux.
